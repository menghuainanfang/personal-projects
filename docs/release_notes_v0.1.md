# ReadingOS 0.1.0

一个离线、本地保存资料的 Windows 阅读应用，支持电子书与纸质书，并将自己的思考放在书籍主页中心。

## 功能

- PDF / EPUB 管理副本导入、重复识别、书库搜索/排序、状态筛选和封面/列表视图。
- PDF 文字高亮、评论、鼠标绘图、直线/圆圈、文本框、整体橡皮擦和撤销/重做。
- EPUB CFI 高亮、评论、字号/行距、目录、书签和阅读位置恢复。
- 置顶主读后感和版本历史、多篇富文本日志、洞见与实践反馈。
- 年度/月度目标和计划书单，按实际完成日期统计。
- 完整资料备份/恢复、用户读书笔记 Markdown 导出、浅/深主题和中文界面。

## 安装

下载 `ReadingOS-0.1.0-win-x64-setup.exe`，为当前用户安装，再通过桌面或开始菜单启动。无需 Node、Rust 或联网使用。

## 限制

无 DRM PDF / EPUB；不支持 OCR、压感、跨版本锚点同步或带批注 PDF 导出。未签名，可能出现 Windows SmartScreen 提示。完整限制和测试范围见 `docs/known_issues.md` 与 `docs/testing.md`。报告问题时请注明应用/Windows 版本与操作步骤，不上传私人图书或资料库。
