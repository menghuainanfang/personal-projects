# 更新记录

## 0.3.0

- 真实采用 Mantine 9.7.3 AppShell、Section、NavLink、ScrollArea 与工具栏，统一书库、书籍、洞见与计划工作台。
- 支持收起导航、全局查找、继续阅读、真实书籍上下文和可记忆的面板宽度；独立阅读器保留专注模式。
- 集成 DayPicker 10.0.2 中文周一日期网格，统一书籍、日志、行动与反馈；支持输入、闰年校验、键盘与嵌套 Esc。
- 月份网格与确认式跨年范围接入计划和批量导入，保留原排期事务与 SQLite v2。
- DOMPurify 更新至 3.4.17；补充两项开源研究、前后截图、时区测试和安装版验收。

## 0.2.1

- 阅读计划新增「导入与安排书单」：粘贴文本、CSV/TSV、书库多选，保存前统一预览。
- PapaParse 5.7.0 解析分隔符、引号和换行；支持列映射、严格 UTF-8、解析错误与条数限制。
- 保守识别已有和可能重复书目；按已有月份负载均匀安排，支持新增上限、改月与临时排除。
- 主进程事务保存整批；重复导入保留原书和原计划，数据库失败整批回滚。SQLite 继续使用 v2。

## 0.2.0

- 暖纸书房、深色主题和统一排版；主读后感置顶，日志与实践使用轻量内容分组。
- 书库一键继续阅读，选文直接写批注，批注摘录及评论引用到日志，日志/洞见返回原始批注位置。
- 每书独立保存字号、行距、PDF 缩放与线宽、高亮颜色、阅读背景和文字配色。
- Radix 对话框提供键盘焦点、Esc 和关闭后的焦点恢复。
- SQLite v1→v2 增量迁移与迁移前资料副本；旧完整备份可恢复并升级。
- 增加基线/新版截图、开源选择、设计规则和新版桌面验收。

## 0.1.0

Windows 本地书库、PDF/EPUB 阅读批注、主读后感、日志、洞见、实践反馈、目标计划、Markdown 导出和完整备份恢复。
