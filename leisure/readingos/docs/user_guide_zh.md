# ReadingOS 使用指南

## 安装和启动

运行 `ReadingOS-0.1.0-win-x64-setup.exe`，为当前用户安装，可选择位置。通过桌面或开始菜单启动。无需安装开发工具；应用自带阅读运行时。

## 建立书库

点击「导入电子书」选择 PDF / EPUB，可多选。程序创建自己的副本，不改动原文件。同一文件再次导入会提示已存在。

点击「添加纸质书」填写书名、作者、标签和分类。每本书都可以选择本地封面、设置阅读状态和日期。「已读」默认填写当天完成日期，可以编辑为实际日期。改回其他状态会清空完成日期。

使用搜索、状态筛选、排序和网格/列表查看书库。点击书籍打开主页。「关联电子版本」可为同一逻辑书增加其他 PDF / EPUB 文件；批注属于具体版本。

## 阅读和批注

- PDF：默认选择文字；选中后点「高亮选文」。工具栏选择高亮/画笔颜色、线宽和缩放。选择「手绘」「直线」「圆圈」后用主鼠标拖动；「文本框」先点击位置，再输入文字。
- 右侧批注可写评论、调整颜色、编辑文本框文字或删除。评论离开输入框后保存。点击批注文字跳到原页/段落。
- 「橡皮擦」点击笔迹或高亮删除整个对象。撤销/重做支持工具栏或 Ctrl+Z / Ctrl+Shift+Z（输入框内保留文字编辑快捷键）。
- EPUB：选中文字后点高亮；字号与行距可调，浅/深主题与应用一致。CFI 定位与高亮在重排和再次打开时恢复。
- 左栏查看目录、添加和删除书签。书签属于当前电子版本。
- 「专注模式」收起侧栏，切回「研读模式」显示侧栏；目录与批注也可以分别收起。

## 记录自己的理解

书籍主页的「我的主读后感」置顶显示，可使用加粗、斜体、标题、列表和引用。正文自动保存，看到「已保存」后退出。版本记录可查看并恢复之前的正文。

阅读日志支持多篇、日期、标题、长文、章节说明或已有批注关联。正文编辑自动保存；保存按钮提交最新标题、日期与来源。关闭正文编辑窗口也会保留已保存内容。主页可以搜索日志。

点击批注或日志的「提炼洞见」建立卡片，也可以独立新建洞见。洞见可关联多本书。点击「化为行动」填写具体实践，设置计划日期、状态，之后记录实践反馈。洞见和行动均可编辑或删除。

## 阅读计划

「阅读计划」里选月份，设置年度和月度本数目标，在书单中勾选本月计划。完成统计按书籍当前的实际完成日期计算，每书计一次，不按开始日期或计划月份重复计数。

## 资料备份

「资料与设置」显示实际资料目录。点击「创建完整备份」保存 `.readingos` 文件。备份包含原书、批注和所有记录，可以复制到其他本地磁盘或私人存储设备。

恢复备份会要求确认替换当前书库；程序会先生成一份恢复前备份。打开数据目录可找到 `before-restore-*.readingos`。书籍主页也可导出主读后感和日志为 Markdown。

## 已知限制

只支持无 DRM 的 PDF/EPUB。暂不导出带批注的 PDF，不处理 OCR、跨版本锚点、压感或其他电子书格式。扫描 PDF 仍可绘图但无法选择原文文字。大文件导入与备份会占用内存并可能短暂等待。安装包未签名，Windows 可能显示 SmartScreen 提示；请按自己的信任判断处理，保持系统安全设置。
