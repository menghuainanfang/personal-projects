# 时间书架与学科书架

首次打开默认时间书架，以加入书库时间组织。切换“时间依据”可看开始、完成或计划；没有此项日期的书出现在“未记录日期 / 尚未开始”。展开年份后选月份，或直接输入年月；返回全部时间取消月份限制。日期正/倒序控制月份，原书籍排序控制组内顺序。计划视图中同一本书可出现于不同月份，书库总数与实际完成数量仍按单一 Book 计算。

学科书架提供全部书籍、未分类、最近 30 天加入。目录支持方向键、展开、选中与路径查找。默认包含子学科，取消勾选只显示当前级别直接归属。名称、父级和排序可在“编辑 / 移动”中修改；最多六层，同父同名和父子环会被拒绝。只能删除没有子类且没有书籍的空学科。

在书籍主页管理多个学科和可选主分类；点击路径可回到该学科。批量操作先逐项选书或“选择当前结果”，再选择添加、移除或替换全部归属。替换会移除之前未勾选的学科，保存前核对操作方式。分类不复制书籍，不改变心得或原书。

全局书库检索匹配标题、作者、关键词、学科完整路径和状态文字；空格分隔的词需全部匹配。检索、状态与当前学科范围是 AND；每个词可匹配任一字段。两个视图共用搜索和状态筛选。自由标签与学科分开管理，旧分类在“旧分类/待整理”中，可逐步重新归类。

完整备份包含分类和所有阅读资料。升级与回退步骤见 iterations/004-data-migration.md；v0.3 不能直接打开 schema v3。
