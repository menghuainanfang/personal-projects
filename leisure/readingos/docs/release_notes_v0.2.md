# ReadingOS 0.2.0

Windows 本地阅读应用，以自己的理解和实践连接原文。

## 新功能

- 书库一键继续阅读，暖纸色与独立深色主题。
- 选文直接写批注；批注摘录和评论引用到日志；日志和洞见返回原文位置。
- 每本书保存阅读字号、行距、背景、文字色、高亮颜色和 PDF 缩放/线宽。
- 主读后感优先的书籍主页，轻量内容分组与键盘对话框。
- 兼容 v0.1 资料和备份，升级前保存数据库副本。

## 安装与反馈

使用 `ReadingOS-0.2.0-win-x64-setup.exe` 为当前用户安装。无需 Node、Rust 或网络。升级前在「资料与设置」创建 `.readingos` 完整备份；数据目录在该页显示，卸载保留资料。

反馈请使用仓库的 ReadingOS issue 模板，说明版本、Windows、文件格式、操作步骤与预期结果；截图和示例请使用可公开的资料。

## 限制

安装包未签名；Windows 可能显示 SmartScreen。支持无 DRM PDF/EPUB；没有 OCR、批注 PDF 导出、连续 PDF 页面或跨版本锚点迁移。Windows 全局 DPI 与其他设备仍需扩大验证；实际测试与边界见 `V02_ACCEPTANCE.md`、`known_issues.md`。
