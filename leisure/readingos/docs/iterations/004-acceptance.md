## 已实现与实测范围

- 时间书架：加入、开始、完成、计划四种依据；年/月目录、快速跳转、正倒序、未记录区域；按 Book ID 去重计数，跨计划月份展示同一实体。
- 学科书架：真正运行 Headless Tree core/react 1.8.0 的节点、键盘、展开、选择、路径搜索与 ARIA。目录创建/改名/移动/排序，防环、同父防重、六层上限；只允许删除空类。
- Book 多学科与可选主分类；批量添加、移除、替换；父类后代并集与仅本级；永久入口和标题/作者/标签/学科路径/状态组合检索。
- 书籍主页完整路径跳转、四种时间事实；原主心得、日志、批注、PDF/EPUB 与来源链保留。
- v1/v2 顺序迁移、v3 完整恢复；升级前一致快照和完整原书归档，事务失败回滚。
- typed 知识投影从真实分类/洞见关联生成，保留来源 ID。
