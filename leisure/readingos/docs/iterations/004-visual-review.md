# v0.4 视觉验收

截图为真实 Electron 桌面窗口，原创 20 本资料，1366×768；高 DPI 下 PNG 像素尺寸随系统缩放增加。before 由已安装 v0.3 生成，after 由当前应用生成；没有个人书名或数据库。六组同名图在 `screenshots/iterations/004/{before,after}`。

| 文件 | 旧版实际表现 | 新版实际表现 |
| --- | --- | --- |
| time-overview | 平铺书籍，无日期索引 | 年/月索引与封面组，四种事实依据 |
| time-month | 无加入月份过滤，仍为平铺 | 单月跳转与当月去重计数 |
| subject-tree | 原有列表 | Headless Tree 学科目录、父类并集 |
| subject-child | 自由文本分类检索 | 完整路径、选中与后代筛选 |
| book-detail | 作者和单文本分类 | 多路径、主分类、真实时间；主心得继续置顶 |
| dark-library | 原有深色书库 | 深色目录与封面，保持主题变量 |

旧版没有时间书架或学科树，因此对应 before 记录当时可用的平铺/检索场景，不将其描述为旧版已经拥有新功能。额外保留原六书基线 book/library/insights/plan/reader/date-form。after 另有三组窗口/缩放图。

沿用暖纸、松绿、宋体内容标题。目录与内容分栏，较窄宽度转为上下结构；顶部压缩装饰性间距，书籍封面保持主要视觉位置。分类路径可换行，树节点计数使用真实去重结果；批量操作为紧凑工具行。主内容仍使用 Mantine Main 单一滚动区，树自身限制高度。

实际检查 1280×720@150%、1366×768@125%、1920×1080@100%；原有 v0.2 回归还覆盖三窗口 × 三缩放 × 四场景。键盘通过树方向键、选中和日期弹层测试。尚未独立验证屏幕阅读器、多显示器系统 DPI 与上千本书的渲染性能。
