# v0.3 工作台与日期设计

书库、书籍主页、洞见与实践、阅读计划、资料设置使用共同 AppShell。56px 工具栏呈现当前位置、返回书库、全局查找、继续阅读、书籍上下文开关与主题；210px 导航可以收起，960px 以下默认收起。主要内容沿用原书房排版，长页面只在 Main 滚动。

书籍上下文默认隐藏，显示真实日志、批注、关联洞见与行动。支持关闭、滚动、240–380px 指针/键盘调整及宽度记忆。点击日志直接编辑；批注与洞见沿用原来源跳转。PDF/EPUB 保持独立阅读器与专注模式，避免双侧栏争夺正文。

日期统一为文字输入加日历按钮。具体日期使用 DayPicker 中文周一网格，提供年/月下拉、今天、可空字段清空；格式仍为 YYYY-MM-DD。计划月份使用年份与 12 个月网格，显示该月已安排数量，浏览不写数据库。批量排期范围有两个独立月份端点、范围预览与显式确认；倒序报错，不互换端点。范围确认后继续使用既有 PapaParse、预览去重、顺序均匀排期与单事务保存。

保留暖纸背景、松绿强调、衬线阅读标题、紧凑工具；不增加渐变、仪表盘卡片或复杂动画。官方样式先加载，再叠加局部 ReadingOS 规则。Mantine 组件和 DayPicker 不套用旧版通用按钮规则。浅深色共用原主题变量。

表单保留 Radix focus trap；内层日历 Tab 不逸出，Esc 优先关闭日历并返回按钮，下次 Esc 关闭表单。非法日期在字段旁报错并阻止表单提交；它不替换已保存的合法日期。书籍状态仍由原状态选择器控制，日期控件不改变完成状态或阅读目标。SQLite schema v2 和 IPC 保持兼容。
