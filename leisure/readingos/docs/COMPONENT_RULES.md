# 组件规则

所有页面共用 `style.css`；对话框共用 `Modal.tsx` 的 Radix primitive，记录表单使用 `RecordDialog.tsx`，正文使用 `Editor.tsx`。不要引入第二套 UI 框架。

- 按钮使用动作名称；主要保存/导入用 primary，删除用 danger。图标入口必须有 title 和可访问名称，切换按钮提供 aria-pressed/expanded。
- 书籍条目由 article 包住两个独立按钮：封面进入资料主页，继续阅读进入原文。不得嵌套按钮。
- 日志、洞见和实践以标题、正文、来源和操作顺序组织；只有真正的浮层使用阴影。
- 对话框有语义标题、Tab 约束、Esc 关闭和返回焦点，保存按钮可见；长表单内部滚动。
- 编辑正文与格式工具分层；自动保存以数据库确认显示。阅读器排队保存偏好、位置与批注，退出等待队列。
- 引用保存 asset 对应的批注 ID，打开时检查存在性、版本与锚点；失效时明确提示，不随意打开其他版本。普通章节说明显示为文字。
- PDF 文本选择为默认模式；绘图由用户显式激活。Ctrl+Z 不截获输入框和正文编辑器的撤销。
- 空态提供一个明确入口，错误反馈使用 alert/status；测试资料只由测试脚本写入，产品首次启动保持空书库。
- 响应式优先换行、收缩导航和收起阅读侧栏。局部 PDF 横向滚动保留，不允许应用外框跟着原书变宽。
- 动效只表现状态，系统减少动态效果时停用。每次新增小字颜色需检查实际背景对比度。
