# 已知限制

- 批量书单支持 UTF-8 CSV/TSV 和逐行纯文本，每批最多 500 条、2 MiB，自动范围最多 120 个月；不包含平台专用导入或 XLSX。书目匹配以书名/作者为准，不能识别不同译名、ISBN 或版本关系，可能重复项需要人工确认。

- 采用 Electron，v0.2 Windows x64 安装包约 126 MiB，内存需求高于 Tauri。本版使用自带运行时分发，NSIS 压缩等级 5，减少构建等待但增加安装包体积。
- 只支持无 DRM PDF / EPUB。扫描 PDF 可以绘图，文字选择需要文档本身有文字层。未实现 OCR、其他格式或跨版本锚点迁移。
- PDF 使用单页导航，当前页可滚动；未提供多页连续渲染、旋转工具或批注拖动/缩放。批注可修改颜色、评论和文本框文字，橡皮擦删除完整对象。
- 不提供带批注 PDF 导出。完整备份保留批注；Markdown 导出包含用户的主读后感和日志。
- EPUB 字号/行距、阅读配色按书持久保存；不能自动修复被外部修改的 EPUB 内容树。
- 书签使用自动命名；封面可以手动选择，未自动提取内嵌封面。
- 大文件导入和备份会读取文件到内存，可能短暂等待；未经大规模书库性能测试。
- 阅读统计每书按当前完成日期计一次，不表示重读次数。暂停/恢复不形成独立阅读周期。
- 主读后感历史保存完整正文版本，长时间使用会增加数据库体积。阅读器撤销/重做只保留本次打开会话的历史。
- 未签名安装包可能触发 SmartScreen。没有自动更新功能；升级前建议保存完整备份。
- Windows 拒绝移动资料目录时恢复会失败，程序会撤回替换并保留现有资料；解除文件占用后可重新恢复。
- 数据库 v2 已验证 v1 升级、旧备份恢复和完整关系保留。旧 v0.1 程序不能直接读取 v2；回退需要迁移前完整备份或 v1 数据库副本与原书目录。
- CI 位于仓库根目录，远程构建状态以 GitHub Actions 页面为准；本机安装版验收已通过。
- 运行时依赖审计没有已知漏洞。开发打包工具依赖仍有 npm 报告的 8 项 moderate 提示；不随应用提供可调用的构建工具。

兼容性验证使用本项目原创样本和当前 Windows 11 机器；尚未覆盖其他 Windows 设备、所有出版商 EPUB 排版、超大或加密文档、屏幕阅读器与多人 beta 的实际反馈。125%/150% 使用 Chromium 缩放检查，没有更改 Windows 全局 DPI；小窗口可收起目录/批注，PDF 页内可横向滚动。自定义颜色由用户选择，可能降低文字对比度。
