# 界面与路径清单

| 场景 | v0.1 真实行为 | v0.2 行为 |
| --- | --- | --- |
| 书库 | 封面网格/列表、搜索、状态筛选、导入 | 保留；每本电子书增加独立继续阅读按钮，封面尊重原图比例 |
| 书籍主页 | 元数据、读后感、日志、洞见、实践、批注 | 主读后感置顶，后续内容使用分组与分隔线；来源跳转定位到原始版本 |
| 阅读器 | 目录、批注、工具、进度、专注 | 工具默认选字；专注收起两侧；按书保存配色/字号/行距/PDF 缩放与线宽 |
| 编辑器 | 格式、即时保存、正文历史 | 轻量工具栏、明确保存状态；大正文区；对话框 Tab 焦点约束、Esc 关闭并返回入口 |
| 批注 | 高亮、评论、洞见；PDF 绘图 | 选文直接写批注；引用到日志同时保存摘录、评论与来源 |
| 计划/资料 | 目标、计划、完成统计、备份恢复 | 功能保留，统一深浅色与布局 |

## 操作步数

以下只统计导航/动作点击，不统计输入文字、拖选、滚动和表单字段。

| 路径 | v0.1 | v0.2 |
| --- | --- | --- |
| 书架到原文 | 点书 → 继续阅读，2 次 | 继续阅读，1 次 |
| 已选文字到高亮 | 高亮选文，1 次 | 高亮选文，1 次 |
| 已选文字到带评论批注 | 高亮 → 评论框 → 移开保存，3 次 | 写批注 → 保存批注，2 次 |
| 批注到带来源日志 | 无直接入口，需手工复制 | 引用到日志 → 保存，2 次 |
| 已保存的引用日志返回原文 | 进入阅读器，但未精确定位 | 返回引用原文，1 次并定位 |
| 日志到洞见 | 提炼 → 保存，2 次 | 保留，2 次 |
| 洞见到行动 | 记录行动 → 保存，2 次 | 保留，2 次 |

PDF 自身的文档内滚动允许横向移动；应用外框、主要工具和表单不应随文档变宽。小窗口的阅读侧栏覆盖内容，可通过目录/批注开关或专注模式收起。
