# 翻译质量与验收

四页原创线性代数讲义包含中英文文字、行内与行间公式、定义、定理、完整证明、编号引用、练习、图、表、脚注与本地参考文献。原创讲义、译文和图示使用 CC0 1.0。验收使用自有样例，未翻译整本受版权保护的教材。

英文与中文样例的数学含义逐段核对：同一常数对所有向量有效；不要求矩阵可逆；证明涵盖零常数；界未被误称为最优；练习保留求最小常数的任务。术语表保留首选、备选、语境和状态。

独立检查项目包括：内容覆盖、数学语义、术语、编译、编号、引用与文献、图表脚注及页面外观。这里的“独立”指分开检查维度；未声称由另一位人工或独立模型审阅。

## 自动验收

`evidence/acceptance.json` 记录 21 项实际通过的检查。`scripts/acceptance.py` 验证数学块内容和出现次数、行间公式顺序、标签及引用顺序、连续物理页标记、两份 PDF 各四页、可解析内部链接、无未解析问号、编译失败、插图缺失、失败不覆盖旧成果、源文保留、带空格路径修复后重建及重复提取。

上游主技能审计：样例为零错误、零警告；上游提供的 8 项审计回归测试通过。测试的具体目的分别是发现漏公式或改符号、引用重定向、覆盖错误、编译失败误报成功、缺图遗漏及继续运行破坏旧成果；遇到失败则修正译稿、资源或构建脚本，相关范围重新验证。

编号实测：定义 1.1、定理 2.1、习题 3.1、公式 (1)-(3)、图 1。Biber 输出参考文献并解析引用。中文样例四页已渲染查看，公式、脚注、图表和参考文献均可读。原文与译文 PDF、可编辑 TeX 和全部构建日志均保留在工作区。

MinerU 本地 basic 解析与重复解析均已运行。抽取稿覆盖四页，保留范数、矩阵乘积、统一界和证明不等式；它保留了部分页眉页脚，并将图标为文档库定位符。因此抽取稿作为翻译辅助，最终结构与插图继续依据原稿。

## 每章记录

进度状态使用 `pending`、`translated`、`reviewed`。`reviewed` 只在完成回源比较、编号与引用检查、编译和页面检查后记录。每章记录物理页范围、印刷页范围（仅核实后填写）、译稿文件、审校记录及输出位置。

原文疑似错误写入 `review/issues.md`，明确原文位置、观察、译者建议与决策；正文保留原文结论。译者补充不混入源文。

## 限制

字符串数学块比较只能发现本样例中的改变，不能证明任意宏展开后的数学等价，也不能自动判断译文语义。PDF 文字层提取不能可靠恢复复杂公式，扫描 PDF 需要模型解析及回源比较。编译成功不代表翻译正确；实际教材仍需逐章审校。工具安装、帮助命令或端口连通不等同于翻译端到端通过，各工具状态见安装报告。
