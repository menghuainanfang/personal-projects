# Data Science Bookcamp 独立学习专题

状态：**计划中**

本专题以 Leonard Apeltsin 的 *Data Science Bookcamp* 为学习起点，通过独立实现、结果复现和方法扩展来理解书中的数据科学案例。目标不是逐字复制官方源代码，而是把案例转化为可以解释、验证和继续发展的实践项目。

## 学习路径

**理解方法 → 独立实现 → 复现结果 → 修改与扩展 → 原创项目**

## 案例列表

| 编号 | 案例 | 核心主题 | 状态 |
| ---: | --- | --- | --- |
| 01 | [概率模拟](01-probability-simulations/) | 概率、蒙特卡洛模拟、NumPy | 计划中 |
| 02 | [广告点击统计](02-ad-click-statistics/) | 统计推断、假设检验、A/B 测试 | 计划中 |
| 03 | [疫情异常检测](03-outbreak-detection/) | 聚类、地理空间分析、可视化 | 计划中 |
| 04 | [就业市场 NLP](04-job-market-nlp/) | 文本处理、TF-IDF、降维、聚类 | 计划中 |
| 05 | [社交网络预测](05-social-network-prediction/) | 图分析、特征工程、机器学习 | 计划中 |

每个案例开始后会补充 Python 版本、依赖、数据获取方法、运行命令、实验结果与限制。数据集只有在许可证允许时才会随仓库重新分发。

专题的初始学习路线和案例选择受到 Leonard Apeltsin 的 *Data Science Bookcamp* 启发。仓库中的实现、说明、实验和扩展将独立完成，并在使用外部材料时注明来源。
