# 已知限制

- 采用 Electron，Windows x64 安装包约 114 MiB，内存需求高于 Tauri。系统工具链缺少 Rust / C++，本版选择自带运行时完成分发。
- 只支持无 DRM PDF / EPUB。扫描 PDF 可以绘图，文字选择需要文档本身有文字层。未实现 OCR、其他格式或跨版本锚点迁移。
- PDF 使用单页导航，当前页可滚动；未提供多页连续渲染、旋转工具或批注拖动/缩放。批注可修改颜色、评论和文本框文字，橡皮擦删除完整对象。
- 不提供带批注 PDF 导出。完整备份保留批注；Markdown 导出包含用户的主读后感和日志。
- EPUB 字号/行距在当前阅读器会话调整；高亮与阅读位置持久保存，但排版偏好不按书籍保存。不能自动修复被外部修改的 EPUB 内容树。
- 书签使用自动命名；封面可以手动选择，未自动提取内嵌封面。
- 大文件导入和备份会读取文件到内存，可能短暂等待；未经大规模书库性能测试。
- 阅读统计每书按当前完成日期计一次，不表示重读次数。暂停/恢复不形成独立阅读周期。
- 主读后感历史保存完整正文版本，长时间使用会增加数据库体积。阅读器撤销/重做只保留本次打开会话的历史。
- 未签名安装包可能触发 SmartScreen。没有自动更新功能；升级前建议保存完整备份。
- 数据库目前只有 v1：验证了初次建表、重开保留和拒绝较新结构；后续版本的真实迁移必须另行测试。
- CI 配置已准备，尚未在远程 GitHub Actions 执行；未公开上传源码或 release。
- 运行时依赖审计没有已知漏洞。开发打包工具依赖仍有 npm 报告的 8 项 moderate 提示；不随应用提供可调用的构建工具。

兼容性验证使用本项目原创样本和当前 Windows 11 机器；尚未覆盖其他 Windows 设备、所有出版商 EPUB 排版、超大或加密文档、屏幕阅读器与多人 beta 的实际反馈。
