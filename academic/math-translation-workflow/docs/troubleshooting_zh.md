# 故障处理

| 现象 | 处理 |
|---|---|
| 上游退出码为 0，但无译稿 | 使用本地入口核对本次 mono、dual 文件，查看运行日志 |
| 模型服务不可用 | 运行 `本地模型.ps1 start`，查看 `state/ollama/server.stderr.log` |
| 模型不存在 | 启动服务后运行 `本地模型.ps1 pull` |
| 日志触发中文编码错误 | 重应用 `patch_pdf_runtime_encoding.py` |
| 批量译文公式占位符次数改变 | 应用 `patch_formula_placeholders.py`，触发上游逐段回退，并回源核对 |
| 免费在线服务限流 | 使用默认本地 Qwen 路线，在线额度与本机模型无关 |
| TeX 工具找不到 | 在本机 `config.json` 填写实际工具路径 |
| MinerU 图片为 `doc:...` 定位符 | 回源提取图文件，放入译稿资源目录 |

先读取进度与最终输出。已有完整成果时无需重跑全书，按具体页或章节精校。保留有效译文数据库；更换便携包后重新应用配套补丁，当前补丁对应 BabelDOC 0.6.4。
