# 第三方许可

本工作区用于个人学习。原始教材、文章、图示及译本的传播权限由原作品授权决定，不随工具许可证自动取得。

| 内容 | 许可证与义务 |
|---|---|
| MathTranslations Skill | MIT；完整安装保留 LICENSE、NOTICE；legacy 模板和 logo 的授权记录在 NOTICE |
| aimath 评估副本 | MIT；保留来源与 LICENSE、NOTICE；未将其候选术语表宣称为官方数据库 |
| LaTeXTrans | MIT；保留 LICENSE；远端 LLM 服务条款另行适用 |
| PDFMathTranslate-next | AGPL-3.0；本机个人使用；GUI 修改保留上游声明，并记录可复现修改；对外提供修改服务或分发时遵守 AGPL 源码义务 |
| BabelDOC、PyMuPDF 及字体模型资产 | 按各依赖自身许可证；Python 安装的 dist-info 和便携包保留通知；不能把顶层 AGPL 等同于每个模型/字体许可证 |
| MinerU | Apache 2.0 + MinerU 附加条款；超过 1 亿 MAU 或月收入 2000 万美元的合并主体需商业授权；提供第三方在线服务须明确标识使用 MinerU |
| MinerU 模型 | ONNX 模型卡明确原模型许可和署名仍适用；manifest.json 记录 PP-DocLayout、PP-OCR、PP-FormulaNet 与表格模型来源；下载用于本机测试，不重新发布权重 |
| Marker | 未安装；当前代码 Apache-2.0；权重许可为修改的 AI Pubs Open Rail-M，个人研究允许，超出商业门槛需另查授权 |
| 无 LICENSE 的两个参考技能 | 公开可阅读不等于可复用代码；未注册、未嵌入交付实现；证据快照只作本地研究 |
| Ollama | MIT；保留上游 LICENSE，不随仓库分发运行时 |
| Qwen3 4B Instruct | Apache-2.0；本地保留模型许可，不重新分发权重 |
| 教材与论文源作品 | 原文及译稿保留在本机，公开报告不附原书或整本译稿 |
| 样例原稿、译文、图示 | 原创，CC0 1.0；目录中附许可说明 |
| TeX Live 与 Fandol | 复用既有安装，按各组件自身许可；不打包发布整个 TeX 系统 |

安装第三方工具时保留其 LICENSE、NOTICE 与依赖通知；源码的通知位于 `vendor/` 和技能安装目录。公开仓库只提供获取方式，不分发模型与第三方字体。
