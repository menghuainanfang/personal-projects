# 中文操作指南

在项目目录运行 `本地翻译PDF.ps1`，传入完整源文件路径与独立输出目录。可以先选代表页检查，再省略 `-Pages` 翻译全书。

```powershell
.\本地翻译PDF.ps1 -Pdf 'D:\资料\book.pdf' -Pages '25-26,50-52' -Output 'D:\译稿\sample'
.\本地翻译PDF.ps1 -Pdf 'D:\资料\book.pdf' -Output 'D:\译稿\full'
.\本地模型.ps1 stop
```

页码指从 1 开始的 PDF 物理页；指定页码时只输出选择的页面。整书内部每批最多 50 页，再合并为完整中文和双语 PDF。需要网页界面时运行 `快速PDF.ps1`，默认使用本机 Ollama；保持本地引擎设置。

arXiv 只有 PDF 时使用自动入口；有对应版本 LaTeX 时，优先取得源码及图资源，以精译路线保留宏、标签、引用和文献。确认源码版本与所读 PDF 一致。

继续精译前读取项目 `chapters.json`、审校记录和当前源文范围。`pending` 表示待处理，`translated` 表示已有译稿，`reviewed` 表示已回源、编译和页面审校。整书机器初稿完成不改变所有章节的精校状态。

`翻译工具.ps1` 提供 `init`、`extract`、`build`、`audit`、`status`；参数见 `python scripts/workflow.py --help`。源稿、最终交付物和独立构建目录各自保存。

模型、排版资源、译文数据库、最终 PDF、可编辑 TeX 和有效术语表属于长期数据。安装完成的下载包、pip 缓存、构建辅助文件与已合并成功的分批副本可清理；清理前确认完整成品可打开且页数齐全。

代码、原创样例和任务报告可以公开。没有源作品的公开发布授权时，将原文、图文及译稿保留在本机。
