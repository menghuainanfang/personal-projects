# 架构

默认自动路线为 PDFMathTranslate-next + BabelDOC + 本机 Ollama/Qwen3。解析、推理和版面重建分工，输出中文与双语 PDF。Ollama 使用项目独立运行时，监听 `127.0.0.1:11435`，模型位于 `state/ollama/models/`。

内部每批最多 50 页，单 worker 控制资源占用，再合并全书。译文数据库按引擎、参数和原文复用结果。成功判定包含本次输出文件。

精译路线使用 MathTranslations、可编辑 LaTeX、既有 TeX 编译器和回源审校；扫描输入可用 MinerU basic 辅助解析。`workflow.py` 负责准备、提取、构建与审计，翻译由独立步骤完成。

固定便携版本配套三个补丁：GUI 只监听本机并定位项目缓存；批量翻译中公式占位符次数改变时进入上游逐段回退；运行时输出使用 UTF-8。模型、运行时和缓存不提交 Git。免费在线引擎不作为默认整书路线，本地自动路线不调用付费翻译 API。
