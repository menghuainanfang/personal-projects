# 复现说明

## 完整工程

下载[物理教师监督训练与前轮对照ZIP](../../../downloads/变分网格_物理教师监督训练与前轮对照_完整复现包.zip)，
解压到独立目录，进入其中mesh-learning-lab。包内README_物理教师训练.md为新一轮入口。
ZIP包含两轮源码、真实教师、旧/新模型权重、训练损失、原始CSV、网格节点与图像。
仓库的工程与实验目录用于在线阅读，完整运行输入在ZIP中。

## 环境与运行

本次使用Python、NumPy、SciPy、Matplotlib、PyTorch，训练和在线比较采用CPU单线程。
Matplotlib图像使用Microsoft YaHei字体；其他系统可修改字体设置。

~~~powershell
python -m pip install numpy scipy matplotlib torch
python runs/physical_X_01/run.py
python runs/physical_X_01/analyze.py
python runs/physical_teacher_01/study.py
python runs/physical_teacher_01/verify.py
~~~

已有教师与模型会复用；完整重训应先把对应models移出工作目录保留。
study.py在Windows下由主入口启动6个标签生成进程，教师全部生成后才进行训练和串行在线比较。
网页中的两轮中文报告与图像已包含在包内，无需重新计算即可阅读。

执行python runs/physical_teacher_01/report.py，从结果表重新生成第二轮报告与图像。

## 运行口径

两轮都是1200训练/400验证/400测试、宽128、三个种子20261023/24/25、最多2000轮。
新教师物理求解先用3000迭代预算，未收敛可继续到更高上限；本次全部教师在首轮预算内收敛。
线上精修统一使用梯度容差10⁻⁵、3000迭代、30000求值，固定20例、各2次。
机器负载会影响绝对耗时；以本次同批运行的配对结果和实际迭代数为准。
