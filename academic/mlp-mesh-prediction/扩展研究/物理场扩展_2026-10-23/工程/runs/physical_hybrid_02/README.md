# 物理网格监督与传统求解

物理教师训练的网络与 L-BFGS 结合，在20个既定算例上，相对规则初值 L-BFGS 获得1.277倍配对加速；最终能量和插值误差接近。传统优化器本身的改进也很明显，评价网络收益需要使用相同且有竞争力的求解基线。

## 旧网络究竟在训练什么

旧Q分支的每个输入是四个高斯参数：中心横坐标、中心纵坐标、强度、宽度。固定12×12方格剖分有169个节点，其中121个内部节点，每个内部节点两个自由度。

教师生成与网络训练是两个独立过程：

1. 固定规则物理网格X0，在单元中心采样标量监控函数m。
2. 最小化冻结X0上的Winslow型计算坐标能量，得到Q*。早期可以迭代求解；当前扩展版利用二次型结构直接解稀疏方程。
3. 在(Q*, X0)之间建立分片线性映射，在给定参考计算网格Q0上求值，得到物理网格X*。
4. Q网络用高斯参数预测内部位移Q*−Q0，以归一化位移MSE训练；预测阶段还需重建X。另一旧X网络直接学习上述重建后的X*−X0。

因此旧网络学习的是教师终点映射，没有学习逐步优化过程，也没有直接按函数插值误差训练。Q标签误差较小并不自动意味着重建X的误差、插值误差或求解时间更好。Q路线有额外重建成本，但不能仅凭这一点判断其效果差；它的冻结二次目标有高效稀疏直接解。

## 物理坐标路线

现有物理教师分支在 `../physical_teacher_01/`：从规则X直接优化Huang型物理能量，得到X教师标签，再训练参数到内部物理位移的网络。不会先优化Q再重建。

该分支已有1200训练、400验证、400测试教师和三个训练种子。本实验复用其中种子20261023的已训练权重，不重新生成相同教师或重复训练。网络为4→128→128→242、Tanh，训练使用监督位移MSE；物理能量在生成教师和在线精修中使用，并不是当前网络训练损失。

物理能量对单元面积、逆Jacobian和当前单元中心处的监控函数一起求导。在线流程为：输入参数→预测X初值→几何合法性处理→同一物理目标下的传统精修。

本目录 `solvers.py` 实现固定边界下的有限内存BFGS方向、正面积与区域约束检查及Armijo步长搜索。原谱梯度法与新方法采用同一能量、梯度容差10⁻⁵、3000迭代和30000能量求值上限。

## 先变分再离散的教师

直接离散与变分法并不互斥：论文方法本身属于变分网格。真正要比较的是：

- 先离散泛函，再对节点求导；
- 先求连续泛函的变分方程，再离散该方程。

对当前冻结物理网格、标量监控函数的Winslow目标，连续驻点条件是：对每个坐标分量和零边界试函数v，

∫Ω (1/m) ∇q · ∇v dx = 0。

`weak_winslow` 独立组装这一P1有限元弱形式，采用与原教师相同的单元中心监控值。它与直接离散二次能量导出的线性系统一致，常数因子不影响驻点。本轮对20例比较了两种教师的全部Q节点，要求最大坐标差小于10⁻¹⁰，同时检查内部方程残差。

因此，这个设置下换成弱形式不会提供不同的教师标签。若改变泛函、度量、有限元空间、求积或边界处理，标签可能不同，需要区分究竟改变了什么。Huang物理目标的独立“先变分后离散”教师尚未实现，本次Winslow等价结论不替代它。

## 本轮实测

固定使用上一物理分支预先选定的20例：原分布、中心偏移、窄强峰、宽弱峰各5例。每种方法重复两次，交替执行顺序，CPU单线程。计时包含预测、合法性处理及求解，不包含加载和指标评估。

|流程|收敛运行数|平均迭代|平均在线时间/秒|最终插值RMSE|
|---|---:|---:|---:|---:|
|规则X＋谱梯度|40/40|206.80|0.8711|0.00965878|
|物理网络X＋谱梯度|40/40|112.05|0.4731|0.00965878|
|规则X＋L-BFGS|40/40|71.85|0.2591|0.00965878|
|物理网络X＋L-BFGS|40/40|53.80|0.2019|0.00965878|

在两端均收敛且相对终点能量差不超过10⁻⁶时计算逐实例、逐重复耗时比，再取几何均值。网络相对同求解器规则初值的配对加速：谱梯度1.859倍，L-BFGS 1.277倍，两组均40/40配对。

物理网络＋谱梯度相对规则X＋L-BFGS的配对加速为0.574倍，说明仅优化网络初值仍不足以超过更好的传统算法。物理网络＋L-BFGS则在更强基线上继续减少成本。

## 验证与结果文件

物理目标的方向有限差分检查用于发现空间度量导数遗漏；独立弱形式与直接离散Q节点及残差比较用于发现教师组装差异；每次物理求解检查输出网格合法性和已接受能量序列单调性。这些检查均通过。

- `run.py`：完整实验入口。
- `solvers.py`：物理L-BFGS及弱形式Winslow教师。
- `results.csv`、`summary.csv`：160次求解及方法汇总。
- `completion.json`：权重来源、容差、配对结果与弱形式最大坐标差。
- `checks.json`：物理梯度核对和逐例弱形式核对。
- 各算例NPZ和history.csv：初末网格及迭代历史。

## 限制与后续问题

本轮使用既有物理教师网络和固定12×12高斯测试子集，验证混合求解成本，不建立跨网格、复杂场或真实PDE泛化结论。20例属于已有测试集，不能视为新的独立测试集。在线计时不包含离线教师和训练成本。

所有物理求解达到数值驻点容差，未证明全局最优。当前物理教师优化的是网格能量，未直接最小化插值或PDE误差；更小网格能量不保证更小任务误差。更换教师的评价应同时保留几何质量、任务误差与同目标求解成本。

后续物理模型扩展应围绕真实场输入和可变节点分支进行，而不是把双峰或波前压缩成同一个四参数高斯代理。若要比较Huang目标的另一种变分离散，应先固定同一目标与度量，再定义弱形式及其求积，避免把更换目标的收益归因于离散顺序。
