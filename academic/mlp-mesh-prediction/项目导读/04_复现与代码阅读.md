# 复现与代码阅读

## 只看成果

先读项目总览和结论，再打开第四轮论文。第五轮新增泛化与数学分析写在中文补充报告，不覆盖历史论文。离线HTML需下载打开；论文PDF可在GitHub预览。

## 数值复现

从仓库根目录进入：

~~~powershell
Set-Location 'academic/mlp-mesh-prediction/工程与历轮实验'
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Set-Location 'experiments/round5_generalization'
& '..\..\.venv\Scripts\python.exe' run_all.py
~~~

使用整理版ZIP时，先进入解压后的课程项目根目录，再进入工程与历轮实验；创建环境和后续运行命令相同。

第五轮不重训，不重建旧200个教师；它生成60个新评估参考并比较三种初值，保留每个失败和不加速例。只用已有结果重建新图表、中文报告，加--reports-only。

原始工程、第三轮和第四轮各自run_all.py可在各目录运行。完整重建历史PDF/网页另需XeLaTeX/ctex、Node与原报告生成器依赖。第五轮Markdown和PNG不依赖这些排版工具。

## Python阅读顺序

1. src/common.py：规则网格、三角连接、边界和高斯参数。
2. src/network.py：4→64→64→242网络，归一化及预测。
3. src/variational_mesh.py、src/teacher.py：旧Q能量、梯度、Armijo及R重建。
4. experiments/round4_direct_physical/physical.py：独立物理能量和自动微分。
5. experiments/round5_generalization/study.py：新场定义、规模适配、同目标比较与计时。
6. test_study.py和verify.py：梯度、插值方向、边界、下降和理论面积界。

先用一个新同分布参数理解数组，再看论文波前。读一组保存的NPZ与CSV，比一开始完整重跑全部实验更容易核对含义。
