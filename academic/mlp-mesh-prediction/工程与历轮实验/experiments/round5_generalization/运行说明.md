# 运行说明与代码阅读

本目录从上两级基础工程读取200个旧教师的训练配置、X模型和第三轮Q模型。新数据只用于评估，没有重训。先按基础工程的requirements.txt准备Python依赖；本轮只生成Markdown和数值图表，不需要Node或LaTeX。

在本目录执行：

~~~powershell
python run_all.py
~~~

步骤为三个单测、60个独立问题的三初值/三重复比较、四个论文平滑核验、一个Q Hessian性质核验、状态与指标检查、中文图表与报告。

只用已保存的数据重建图表和报告：

~~~powershell
python run_all.py --reports-only
~~~

主要文件：

|文件|用途|
|---|---|
|study.py|新参数目录、解析场、度量、位移插值适配、独立物理能量、同目标优化和计时|
|paper_checks.py|原论文Example 4.1的Huang Q泛函平滑核验|
|theory_checks.py|冻结Q Hessian的数值例证|
|verify.py|保存状态、下降、梯度、面积界和成对比较条件|
|build_report.py|由真实CSV生成中文报告、表格和图|
|test_study.py|新度量梯度、旧高斯目标一致性、跨规模插值与边界|
|文档/数学结论与证明.md|条件命题、证明与反例|

跨规模测试使用参考坐标上的双线性位移场插值，未改输出层。外部波前/双峰的四参数输入是明确固定的高斯代理，不能解释成任意函数编码。

优化采用与第四轮相同的物理目标及BB/Armijo程序结构，开放度量回调以处理真实出现的新场；原第四轮文件未改。比较阈值为梯度1e-5和终点相对能量差1e-7，超预算或不同终点不计入相同精度加速。全部原始状态和计时保留。
