# 个人项目集

这是我的个人项目与学习实践仓库，分为学科与学习、兴趣与休闲两类。从数学、数据科学和实际问题建模，到个人阅读、日常数据与小工具探索，分别整理各自的目标、实现和成果。

## 分类入口

| 分类 | 内容 | 详细介绍 |
| --- | --- | --- |
| 学科与学习项目 | 课程实践、教材案例、数学学习工具、方法复现与研究准备 | [academic/](academic/) |
| 兴趣与休闲项目 | 个人阅读、生活记录、趣味数据分析和日常工具 | [leisure/](leisure/) |

各分类的 README 汇总项目内容、当前状态和使用入口；具体项目的 README 提供运行方法、成果、验证与限制。

## 项目组织

项目按主要用途归类。学科项目侧重概念、方法、实验和可复现成果；兴趣项目侧重个人使用与生活中的探索。各项目独立保存代码、测试和说明，当前状态以分类索引和项目文档为准。

新项目可从 [项目 README 模板](docs/PROJECT_README_TEMPLATE.md) 开始，根据实际规模补充问题、数据来源、运行环境、结果与限制。
