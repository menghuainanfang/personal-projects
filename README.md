# 个人项目集

这是我的个人项目与学习实践仓库，用来持续整理从想法、学习和现实问题中发展出来的小项目。内容不限于某一种编程语言或单一领域，可能涉及数学学习、Python 与数据科学、实际问题建模，以及其他感兴趣的探索。

这个仓库既记录完成的作品，也保留正在形成中的项目。每个项目都会明确标注状态，不把计划、实验和已经验证的结果混在一起。

## 项目总览

| 类别 | 项目 | 内容 | 状态 |
| --- | --- | --- | --- |
| 数据科学学习 | [Data Science Bookcamp 独立学习专题](projects/data-science-bookcamp/) | 独立实现、复现并扩展书中的数据科学案例 | 计划中 |

新的数学学习、实际建模和兴趣项目会在正式开始后加入此表，而不会提前创建空目录。

## 项目方向

- **数学学习：** 概念推导、数值实验、可视化和对理论结果的计算验证。
- **实际建模：** 从现实问题出发，建立假设、选择模型、分析结果并说明适用边界。
- **编程与数据科学：** 使用合适的语言和工具完成数据处理、算法实现、实验与应用。
- **兴趣探索：** 收录值得持续推进的工具、模拟、自动化和跨领域小项目。

这些方向是内容索引，不是固定边界。项目以实际问题为中心，可以同时属于多个方向。

## 工作方式

项目通常按照以下路径推进：

**问题与目标 → 实现 → 验证 → 记录 → 迭代**

1. 说明要解决的问题、项目范围和完成标准。
2. 用适合问题的方法完成一个可以运行的实现。
3. 通过计算、实验、测试或资料核对结果。
4. 记录环境、数据来源、执行方法、结论和限制。
5. 根据新问题继续改进，或在目标完成后明确结束项目。

`projects/` 保存实际项目与专题集合；`docs/` 保存跨项目使用的文档模板。代码、数据、测试、图表和 Notebook 只在具体项目需要时创建。

## 项目文档约定

每个项目应尽量说明：

- 项目要回答的问题与当前状态；
- 数据或资料的来源及使用许可；
- 所使用的方法、工具和主要假设；
- 环境配置与运行方式；
- 实验结果、限制和后续方向；
- 在项目过程中获得的主要认识。

新项目可以从 [`docs/PROJECT_README_TEMPLATE.md`](docs/PROJECT_README_TEMPLATE.md) 开始整理，但模板可以根据项目规模简化。

## 可复现性与数据

需要复现的项目会记录运行环境、依赖、数据获取方式和执行命令。随机过程会在必要时记录随机种子和相关环境信息。

数据集只有在许可证允许时才会随仓库分发；否则，项目文档会提供原始来源和获取方法。第三方材料仍遵循各自的许可证与使用条款。
